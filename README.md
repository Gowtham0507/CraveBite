# CraveBite - Food Delivery Application

CraveBite is a comprehensive full-stack food delivery application featuring a robust backend and a modern, responsive frontend.

## Features
- **User Authentication:** Secure registration and login.
- **Restaurant & Menu Browsing:** Explore local restaurants and their available dishes.
- **Cart Management:** Add items to cart and review orders before checkout.
- **Order Processing:** Place orders with multiple payment options (Online & COD).
- **Payment Integration:** Secure simulated payment flows.
- **Admin Dashboard:** Admin interface to accept or reject incoming orders.
- **Email Notifications:** Automated emails for registration, order confirmation, and cancellation.

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, React Router DOM
- **Backend:** Java 17, Spring Boot, Spring Security, MongoDB
- **Tools:** Maven, Node.js

## Project Setup

### Backend
1. Navigate to the `backend` directory.
2. Update `application.properties` with your MongoDB URI and SMTP credentials.
3. Run the application:
   ```bash
   mvn spring-boot:run
   ```

### Frontend
1. Navigate to the `frontend` directory.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
